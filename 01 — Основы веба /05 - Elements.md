# ДЗ 05. Эксперимент в Elements

Провел эксперимент в DevTools на сайте github.com.

1. **Изменение заголовка через Edit as HTML:**
Выбрал главный заголовок на странице, нажал "Edit as HTML" и заменил текст на свой вариант. Текст на странице сразу поменялся.

2. **Добавление свойства outline:**
В панели Styles выбрал этот же элемент и добавил ему свойство `outline: 2px solid red;`. Вокруг заголовка появилась четкая красная рамка.

3. **Итоговый font-size в Computed:**
Перешел во вкладку Computed для этого элемента. Нашел свойство `font-size`, его итоговый размер составил 32px.

4. **Почему изменения пропадут после перезагрузки:**
Потому что DevTools меняет код только локально в самом браузере (в оперативной памяти компьютера). Когда мы обновляем страницу, браузер заново скачивает чистые файлы с серверов GitHub, и все наши временные правки стираются.
